# 数据分析操作文档

## 1. 用户目标描述

### 1.1 分析目标
用户希望对haoxianglai.xlsx中的仓库订货数据进行深入分析，主要目标是：
1. **各仓库订货数量和频率分布分析**：了解不同仓库的订货模式，包括订货数量的分布特征和订货频率的高低
2. **未来30天订货数量预测**：预测从2025年11月5日到2025年12月4日（未来30天）期间，各个省份各个仓库的总订货数量

### 1.2 数据概况
- 数据文件：haoxianglai.xlsx
- 数据时间范围：2025年7月9日 - 2025年10月5日（共88天）
- 数据记录数：252条
- 预测目标期：2025年11月5日 - 2025年12月4日（未来30天）

## 2. 数据字段详细描述

### 2.1 数据结构
数据包含5个字段，共计252条记录：

| 字段名称 | 数据类型 | 字段含义 | 备注 |
|---------|---------|---------|------|
| 经营组织 | 字符串 | 订货的部门或组织单位 | 共7个不同的经营组织 |
| 省份 | 字符串 | 仓库所在的省份 | 共23个不同的省份 |
| 经营仓库 | 字符串 | 具体的仓库名称 | 共47个不同的仓库 |
| 订货数量（件） | 数值 | 每次订货的数量 | 范围：20-730件，平均值118.84件 |
| 订货日期 | 日期 | 订货发生的日期 | 2025年7月9日至2025年10月5日 |

### 2.2 关键统计信息
- **经营组织分布**：华中华南(103条)、华南(68条)、华北(29条)等
- **主要省份**：江苏(47条)、山东(35条)、安徽(30条)、河南(20条)
- **主要仓库**：山东济南仓(11条)、江苏南京仓(9条)等
- **订货数量特征**：平均118.84件，中位数62.5件，存在较大的变异性

## 3. 分析思路和步骤

### 3.1 第一阶段：数据初步探察
1. **数据质量检查**
   - 检查缺失值、异常值
   - 验证数据类型和格式正确性
   - 检查时间序列的连续性

2. **描述性统计分析**
   - 各维度（组织、省份、仓库）的订货频次分布
   - 订货数量的分布特征（均值、中位数、标准差、分位数）
   - 时间序列的基本趋势分析

3. **数据可视化初步**
   - 各仓库订货数量分布图
   - 订货频率统计图
   - 时间序列趋势图

### 3.2 第二阶段：深入分析
1. **订货模式分析**
   - 各仓库订货数量的统计分布
   - 订货频率的高低分布
   - 不同经营组织、省份的订货特征对比
   - 订货周期性分析（是否有周模式、月模式等）

2. **相关性分析**
   - 不同仓库间订货的相关性
   - 时间序列的自相关性分析
   - 外部因素影响分析（如果有的话）

### 3.3 第三阶段：预测建模
1. **特征工程**
   - 时间特征提取（星期几、月份等）
   - 滞后特征构建
   - 移动平均特征
   - 季节性特征

2. **预测模型选择**
   - 时间序列模型（ARIMA、季节性ARIMA等）
   - 机器学习模型（随机森林、XGBoost等）
   - 深度学习模型（LSTM等，如果数据量足够）

3. **模型训练和验证**
   - 划分训练集和验证集
   - 模型参数调优
   - 交叉验证

4. **预测结果生成**
   - 预测未来30天各省各仓的总订货数量
   - 计算预测置信区间
   - 评估预测准确性

### 3.4 第四阶段：结果呈现
1. **分析报告生成**
   - 订货分布和频率的可视化图表
   - 预测结果的表格和图表展示
   - 关键发现和业务建议

2. **输出文件**
   - 【数据初步探察.xlsx】：详细的数据探察结果
   - 【数据分析报告.pdf】：完整的分析报告和预测结果
