# 生产排产计划系统产品设计文档

## 1. 产品概述

### 1.1 产品定位
工厂生产排产计划系统是一个基于Web的应用程序，旨在帮助工厂根据原物料库存、产线产能、生产订单需求等信息进行智能化的生产计划排产。

### 1.2 核心价值
- 提高生产计划制定效率，减少人工排产时间
- 优化资源配置，降低生产成本
- 实时监控生产进度，及时发现和解决问题
- 支持移动端查看，随时随地掌握生产动态

### 1.3 目标用户
- **生产计划员**：负责制定和调整生产计划，管理订单排产
- **采购人员**：查看生产计划，安排原物料采购和调拨

## 2. 功能模块设计

### 2.1 基础数据管理模块
**功能描述**：管理系统的基础配置数据
- 工厂信息管理（包含仓库和产线配置）
- 产线信息管理（前道/后道产线设置）
- 品线分类管理
- 产品（SKU）信息管理
- 原物料信息管理
- 物料清单（BOM）管理
- 数据导入功能（支持Excel格式）

### 2.2 订单管理模块
**功能描述**：管理生产订单和排产订单
- 生产订单管理（创建、编辑、查看）
- 订单优先级设置
- 订单拆分功能（生产订单拆分为排产订单）
- 订单状态跟踪

### 2.3 库存管理模块
**功能描述**：实时监控和管理库存状态
- 当前库存查看
- 库存变动推演（以半天为时间单位）
- 原物料需求预测
- 库存预警功能

### 2.4 智能排产模块
**功能描述**：系统的核心算法模块
- 自动排产算法（按优先级和完工时间排序）
- 原物料可用性检查
- 产线产能占用计算
- 采购/调拨订单建议生成
- 排产冲突检测和提醒

### 2.5 可视化展示模块
**功能描述**：多种图表展示排产结果
- 甘特图展示（主要功能）
- 产线负载图
- 库存趋势图
- 订单完成率统计
- 移动端适配图表

### 2.6 手动调整模块
**功能描述**：支持人工干预和调整
- 排产计划手动调整
- 订单优先级调整
- 产线重新分配
- 调整记录追踪

### 2.7 报表分析模块
**功能描述**：生成各类分析报表
- 生产效率报表
- 原物料消耗报表
- 产线利用率报表
- 历史排产记录查询
- 数据导出功能

### 2.8 用户权限管理模块
**功能描述**：管理用户权限和访问控制
- 用户账号管理
- 角色权限设置（生产计划员/采购人员）
- 功能访问控制
- 操作日志记录

## 4. 业务流程

### 4.1 排产流程
1. **数据准备**：导入或录入基础数据（工厂、产线、物料等）
2. **订单录入**：创建生产订单，设置优先级和完工时间
3. **自动排产**：系统按算法进行智能排产
4. **结果展示**：甘特图展示排产结果，标识异常订单
5. **手动调整**：生产计划员根据实际情况调整排产
6. **计划确认**：确认最终排产计划
7. **执行监控**：跟踪生产执行情况

### 4.2 库存管理流程
1. **库存初始化**：录入当前实际库存
2. **需求计算**：根据排产计划计算原物料需求
3. **库存推演**：模拟未来库存变动
4. **采购建议**：生成采购和调拨建议
5. **订单跟踪**：跟踪采购和调拨订单执行情况

## 5. 核心算法逻辑

### 5.1 排产算法
1. 按工厂分组排产订单
2. 组内按优先级和完工时间排序
3. 逐个检查原物料可用性
4. 计算产线产能占用
5. 生成排产时间表

### 5.2 库存推演算法
1. 以半天为单位进行时间推演
2. 考虑采购/调拨入库
3. 考虑生产领料出库
4. 计算各时间点的可用库存

## 6. 异常处理机制

### 6.1 排产异常类型
- 原物料不足（库存/采购不及时）
- 产线产能冲突（时间重叠）
- 订单无法按时完成

### 6.2 异常处理方式
- 突出显示异常订单
- 提供异常原因说明
- 给出解决建议
- 支持手动调整解决

### 7.1 数据安全

- 数据传输加密

### 7.2 数据备份

### 8.1 响应时间

### 8.2 并发支持
- 支持多用户同时操作
- 数据一致性保证
- 冲突检测和解决
