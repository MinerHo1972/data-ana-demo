# 电商销售预测系统 - 三种预测方法实现

## 系统概述

我为你的电商销售预测需求创建了一个完整的预测系统，包含三种初期预测方法：**SARIMA、XGBoost和Prophet**。这个系统能够处理按周统计的多商品销售数据，预测未来13周的销售情况。

## 预测方法详解

### 1. SARIMA时间序列预测

**特点：**
- 基于统计学的时间序列分析模型
- 适合具有明显季节性和趋势的数据
- 理论成熟，可解释性强

**核心算法：**
```python
# SARIMA(p,d,q) × (P,D,Q,s) 模型
# p: 自回归阶数, d: 差分阶数, q: 移动平均阶数
# P: 季节性自回归阶数, D: 季节性差分阶数, Q: 季节性移动平均阶数
# s: 季节性周期（周数据通常为52）

model = SARIMAX(timeseries,
              order=(p, d, q),
              seasonal_order=(P, D, Q, 52))
```

**实现文件：** `sarima_forecast.py`

**适用场景：**
- 商品销售有明显的年度季节性
- 数据相对稳定，异常值较少
- 需要可解释的预测结果

### 2. XGBoost机器学习预测

**特点：**
- 基于梯度提升的决策树模型
- 能处理复杂的非线性关系
- 预测精度高，支持特征工程

**核心算法：**
```python
# 特征工程
- 时间特征：年、月、季度、周数
- 滞后特征：前1、2、4、8、13周销量
- 滚动统计：移动平均、标准差、最大最小值
- 季节性特征：正弦余弦变换、节假日标识

# 模型训练
model = XGBRegressor(
    n_estimators=100-200,
    max_depth=3-7,
    learning_rate=0.1
)
```

**实现文件：** `xgboost_forecast.py`

**适用场景：**
- 数据特征丰富，影响因素多样
- 销售模式复杂，非线性关系明显
- 需要高预测精度

### 3. Prophet商业预测

**特点：**
- Facebook开源的商业预测模型
- 自动处理季节性和节假日
- 使用简单，适合快速部署

**核心算法：**
```python
# Prophet模型
model = Prophet(
    yearly_seasonality=True,    # 年季节性
    weekly_seasonality=False,   # 周数据不需要周季节性
    changepoint_prior_scale=0.05,
    seasonality_prior_scale=10.0
)

# 添加自定义季节性和节假日
model.add_seasonality(name='quarterly', period=91.25, fourier_order=5)
model.add_regressor('is_holiday_season')
```

**实现文件：** `prophet_forecast.py`

**适用场景：**
- 需要快速部署和迭代
- 有明显的节假日效应
- 业务用户友好的预测工具

## 数据预处理流程

### 1. 数据清洗
- 处理缺失值和异常值
- 确保数据按周统计
- 统一日期格式

### 2. 特征工程
- **时间特征**：年、月、季度、周数、是否节假日
- **滞后特征**：前1、2、4、8、13周的销售数据
- **滚动统计**：移动平均、标准差、最大最小值
- **季节性特征**：正弦余弦变换捕获周期性

### 3. 数据验证
- 检查时间序列的平稳性
- 识别异常值和离群点
- 验证数据的完整性

## 预测评估指标

### 1. 绝对误差指标
- **MAE（平均绝对误差）**：`mean(|actual - predicted|)`
- **RMSE（均方根误差）**：`sqrt(mean((actual - predicted)²))`

### 2. 相对误差指标
- **MAPE（平均绝对百分比误差）**：`mean(|(actual - predicted)/actual|) × 100%`
- **WAPE（加权平均绝对百分比误差）**：`sum(|actual - predicted|) / sum(|actual|) × 100%`

### 3. 模型诊断
- **AIC/BIC**：模型拟合优度
- **交叉验证**：时间序列分割验证
- **残差分析**：检查预测误差的随机性

## 方法选择建议

### 根据数据特点选择：

1. **数据稳定，有季节性** → SARIMA
   - 销售量相对稳定
   - 有明显的年度季节性
   - 异常值较少

2. **数据复杂，多因素影响** → XGBoost
   - 销售受多种因素影响
   - 非线性关系明显
   - 数据量较大

3. **快速部署，业务友好** → Prophet
   - 需要快速得到预测结果
   - 有节假日效应
   - 业务用户需要理解和使用

### 根据业务场景选择：

1. **库存管理** → SARIMA
   - 需要稳定的预测
   - 重视可解释性

2. **营销规划** → XGBoost
   - 需要高精度预测
   - 考虑多方面因素

3. **销售报告** → Prophet
   - 快速生成预测
   - 图表展示友好
