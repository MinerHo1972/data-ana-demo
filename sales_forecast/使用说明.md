# 4G销售预测系统使用说明

## 系统概述

我已经为你创建了一个专门处理4G产品销售数据的预测系统，能够处理你的两列数据（周数和销售量），并使用三种不同的算法预测未来13周的销售情况。

## 文件说明

### 核心预测文件

1. **`single_product_forecast.py`** - 完整版预测系统
   - 依赖：pandas, numpy, statsmodels, xgboost, prophet
   - 功能：完整的三种预测方法实现
   - 输出：Excel文件包含详细预测结果

2. **`simple_4g_forecast.py`** - 简化版演示
   - 依赖：无（仅Python标准库）
   - 功能：演示三种预测方法的核心逻辑
   - 输出：控制台显示预测结果

3. **`sales_4g_byweek.xlsx`** - 你的实际数据文件
   - 格式：两列（第几周，销售量）
   - 用途：预测系统的输入数据

## 数据格式要求

你的Excel文件应该包含两列：

| 列A | 列B |
|-----|-----|
| 周数 | 销售量 |
| 1    | 85   |
| 2    | 92   |
| 3    | 88   |
| ...  | ...  |

**注意事项：**
- 周数建议连续（1, 2, 3, ...）
- 销售量为数值类型
- 建议至少有12周的历史数据
- 数据无缺失值

## 三种预测方法详解

### 1. SARIMA时间序列预测
- **特点**：统计学方法，适合季节性数据
- **优势**：理论成熟，结果可靠，可解释性强
- **适用**：数据稳定，有明显季节性模式

### 2. XGBoost机器学习预测
- **特点**：基于决策树的集成学习
- **优势**：预测精度高，能处理复杂模式
- **适用**：数据复杂，多因素影响

### 3. Prophet商业预测
- **特点**：Facebook开源的商业预测工具
- **优势**：使用简单，自动处理节假日效应
- **适用**：快速部署，业务友好

## 预测结果解读

### 输出文件结构

生成的Excel文件包含以下工作表：

1. **原始数据** - 你的历史销售数据
2. **SARIMA预测** - SARIMA方法的预测结果
3. **XGBoost预测** - XGBoost方法的预测结果
4. **Prophet预测** - Prophet方法的预测结果
5. **预测汇总** - 三种方法的对比汇总

### 预测结果说明

每个预测工作表包含：
- `week` - 未来周数
- `predicted_sales` - 预测销售量
- `lower_bound` - 预测下限（置信区间）
- `upper_bound` - 预测上限（置信区间）
- `method` - 预测方法标识

## 方法选择建议

### 根据数据特点选择

**数据稳定且有季节性** → 选择 **SARIMA**
```
示例：年度促销模式明显，销量波动规律
```

**数据复杂且多因素影响** → 选择 **XGBoost**
```
示例：受市场、竞争、价格等多重因素影响
```

**需要快速业务部署** → 选择 **Prophet**
```
示例：需要快速生成销售报告和预测
```

### 根据使用场景选择

**库存管理** → 推荐SARIMA
- 保守预测，稳定性好
- 考虑预测区间下限

**销售目标** → 推荐XGBoost
- 高精度预测，考虑增长潜力
- 结合市场分析

**快速报告** → 推荐Prophet
- 自动化处理，易于理解
- 包含趋势分析
