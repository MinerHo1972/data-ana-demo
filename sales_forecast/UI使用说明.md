# 4G销售数据预测系统 - UI使用说明

## 系统概述

本系统提供了一个功能完整的图形化用户界面，用于4G销售数据的预测分析。系统集成了SARIMA和Prophet两种优秀的预测算法，支持数据导入、预测分析、**深度数据挖掘**、规律性识别和结果展示等功能。

### 🆕 v2.0 新增功能
- **季节性规律拆分**: 自动识别和展示数据的月度、季度、周度季节性模式
- **趋势性规律拆分**: 多维度趋势分析，包括移动平均、增长率、时间序列分解
- **增强的可视化**: 5个专业分析标签页，提供全面的数据洞察
- **智能图表更新**: 数据加载后自动分析并展示规律性图表

## 功能特点

### 🎯 核心功能
- **数据导入**: 支持Excel(.xlsx, .xls)和CSV文件格式
- **智能算法**: 集成SARIMA和Prophet两种预测算法
- **实时预测**: 支持自定义预测周期(1-52周)
- **结果分析**: 提供详细的模型评估指标
- **可视化展示**: 自动生成预测对比图表
- **数据导出**: 支持CSV格式结果导出和PNG图表导出

### 📊 算法介绍

#### SARIMA算法
- 专门针对时间序列数据设计
- 能够有效捕捉数据的季节性模式
- 适合具有明显周期性的销售数据
- 在百分比精度(MAPE)方面表现优异

#### Prophet算法
- Facebook开源的商业预测工具
- 能够同时处理趋势、季节性和节假日效应
- 对异常值有较好的鲁棒性
- 在整体精度(MAE)方面表现最佳

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

## 使用步骤

### 1. 启动程序
```bash
# 方式1: 使用启动脚本
python 启动预测系统.py

# 方式2: 直接运行UI
python forecast_ui.py
```

### 2. 数据准备
- 准备包含时间序列数据的Excel或CSV文件
- 文件应包含至少两列：时间列和销售量列
- 时间格式支持标准日期格式或中文周数格式

### 3. 导入数据
1. 点击"浏览"按钮选择数据文件
2. 点击"加载数据"按钮导入数据
3. 系统会自动显示数据信息概览

### 4. 设置预测参数
1. 在"预测周期数"中输入要预测的周数(1-52)
2. 选择预测算法：
   - SARIMA算法
   - Prophet算法
   - 两种算法都使用(推荐)
3. 点击"开始预测"按钮

### 5. 查看结果

#### 预测结果标签页
- 显示详细的预测数值表格
- 包含预测周期、各算法预测值、实际值(如果有)、差异分析

#### 模型评估标签页
- 显示各算法的评估指标：
  - MAE(平均绝对误差)
  - MSE(均方误差)
  - RMSE(均方根误差)
  - MAPE(平均绝对百分比误差)
- 提供模型对比和最佳模型推荐

#### 图表展示
- 实时显示预测对比图表
- 包含历史数据、预测值和实际值的可视化对比

### 6. 导出结果
- **导出预测结果**: 将预测数据导出为CSV格式
- **导出图表**: 将可视化图表导出为PNG格式图片

## 数据格式要求

### 支持的文件格式
- Excel文件: .xlsx, .xls
- CSV文件: .csv

### 数据结构
- 必须包含两列数据
- 第一列: 时间信息
- 第二列: 销售量数值

### 时间格式支持
- 标准日期格式: 2022-01-01, 2022/01/01
- 中文周数格式: "2022年第1周(周01月02日)"
- 其他常见时间格式

## 使用技巧

### 1. 数据质量检查
- 确保数据没有缺失值
- 销售量数据应为数值型
- 时间序列应保持连续性

### 2. 预测参数优化
- 根据业务需求选择合适的预测周期
- 建议使用两种算法进行对比
- 优先考虑MAPE较低的算法

### 3. 结果解读
- 关注MAPE指标，越小表示预测越准确
- 观察预测值与实际值的差异趋势
- 结合业务知识分析预测结果的合理性

## 常见问题

### Q: 程序启动失败怎么办？
A: 检查Python环境和依赖库是否正确安装，确保所有必需的包都已安装。

### Q: 数据导入失败怎么办？
A: 检查文件格式是否正确，确保文件包含至少两列数据，第一列为时间，第二列为数值。

### Q: 预测结果不准确怎么办？
A:
- 检查历史数据的质量和完整性
- 尝试调整预测周期
- 使用更多历史数据进行训练
- 结合多种算法的结果进行综合判断

### Q: 如何处理中文日期格式？
A: 系统已内置支持中文周数格式，如"2022年第1周(周01月02日)"，会自动解析为标准日期。
